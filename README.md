# 청년부 회계 관리 & 이중 결재 문서 자동화 웹앱 (TDS)

토스 디자인 시스템(TDS Light Mode)을 기반으로 구축된 **교회 청년부 회계 장부 · 목장별 심방/회식비 시각화 · 월별 이중 결재 문서(A4 결산 보고서 + 영수증 증빙철) · 예산/청구서 자동 생성** 웹 애플리케이션입니다.

## 주요 기능

1. **모바일/웹 회계 장부 (`LedgerView`)**
   - 통장 쪼개기 탭 필터 (`전체` / `일반회계(운영비)` / `수련회·행사비` / `목적헌금·선교`)
   - 영수증 미증빙 지출 자동 감지 배너 및 원터치 필터링
   - 클라이언트 Canvas API 기반 영수증 사진 자동 리사이징(최대 폭 1200px, JPEG 0.8) 및 가상 영수증 생성기

2. **목자 공유용 목장별 심방비·회식비 지출 현황 (`MokjangDashboardView`)**
   - 전체 목장 배정 예산 대비 심방비·회식비 소진율 프로그레스 바 및 잔여 한도 비교표
   - 특정 목장 단독 필터링(목자 공유 전용 뷰) 및 카카오톡 공유용 정산 브리핑 문구 원클릭 복사

3. **월별 이중 결재 인쇄 센터 (`PrintCenterView`)**
   - 일자순 자동 증빙 넘버링 엔진(`#01`, `#02`...)으로 **[문서 1: 월별 회계 결산 보고서]**와 **[문서 2: 영수증 증빙철]** 1:1 매칭
   - A4 1장당 2분할(좌우 2열) / 4분할(2×2 격자) 자동 페이지 분할 및 인쇄용 영수증 스캔 보정 필터

4. **연초·연말 예산안 & 수련회 재정 청구서 빌더 (`BudgetBuilderView`)**
   - 실시간 한글 금액 변환기 (`일금 일백오십사만 원정 (₩1,540,000)`)
   - 멀티라인 자동 높이 확장 테이블 셀 및 **연간 예산안 관/항 구조 ↔ 앱 전체 장부 카테고리 실시간 동기화**

5. **Google Sheets + Google Drive 서버리스 연동 (`SyncManager`)**
   - LocalStorage 오프라인 폴백(Optimistic UI) 및 엑셀(CSV) / JSON 백업·복원
   - 앱 내 `[⚙️ 연동 설정]` 모달에서 복사해 바로 배포 가능한 완성본 `Code.gs` 제공

## 로컬 실행 방법

```bash
npm install
npm run dev
```

- 기본 개발 서버 주소: `http://127.0.0.1:4820/`
